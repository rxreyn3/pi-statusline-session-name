# pi-statusline-session-name

Show the current [Pi](https://pi.dev) session name in the interactive statusline/footer.

This is especially useful with [`pi-session-auto-rename`](https://www.npmjs.com/package/pi-session-auto-rename), which automatically calls `pi.setSessionName(...)` after the first prompt. This extension reads that same public session name with `pi.getSessionName()` and displays it as a compact footer status item:

```text
name: Refactor Auth Module
```

No Pi core/source changes are required.

## Features

- Displays the current session name in Pi's built-in footer/statusline.
- Works with names generated by `pi-session-auto-rename` or any extension that calls `pi.setSessionName(...)`.
- Refreshes on Pi lifecycle events and via a lightweight poll so manual renames are picked up too.
- Includes `/session-name-status` to hide, show, toggle, or force refresh the status item.

## Install

### Local development install

From the parent directory containing this package:

```bash
pi install ./pi-statusline-session-name
```

Or run Pi with the extension for only the current invocation:

```bash
pi -e ./pi-statusline-session-name
```

### GitHub install

After this repository is pushed publicly to GitHub:

```bash
pi install git:github.com/rxreyn3/pi-statusline-session-name
```

You can also pin a tag or branch:

```bash
pi install git:github.com/rxreyn3/pi-statusline-session-name@v0.1.0
```

### npm install

After the package is published to npm:

```bash
pi install npm:pi-statusline-session-name
```

## Pairing with pi-session-auto-rename

Install both packages:

```bash
pi install npm:pi-session-auto-rename
pi install git:github.com/rxreyn3/pi-statusline-session-name
```

Then start a new Pi session and send a prompt. Once `pi-session-auto-rename` generates a title, this extension will show it in the footer/statusline.

You can also manually regenerate the name with:

```text
/name-ai
```

The statusline should update automatically shortly after the name changes.

## Command

```text
/session-name-status [on|off|toggle|refresh]
```

Examples:

```text
/session-name-status off
/session-name-status on
/session-name-status refresh
```

With no argument, the command toggles visibility.

## Publishing checklist

To make this available to other users and eligible for discovery on <https://pi.dev/packages>:

1. Ensure `package.json` includes the `pi-package` keyword and a `pi.extensions` manifest.
2. Commit the package to git.
3. Create a public GitHub repository at `github.com/rxreyn3/pi-statusline-session-name` and push it.
4. Verify GitHub install:

   ```bash
   pi install git:github.com/rxreyn3/pi-statusline-session-name
   ```

5. Optionally publish to npm:

   ```bash
   npm pack --dry-run
   npm publish --access public
   ```

6. Verify npm install:

   ```bash
   pi install npm:pi-statusline-session-name
   ```

The Pi package gallery displays packages tagged with `pi-package`; publishing publicly via npm is the best path for broad package-gallery discoverability.
